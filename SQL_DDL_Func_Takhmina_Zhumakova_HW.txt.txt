The final result addresses the questions you posed in Task 6 by providing explanations and solutions. Here's a concise summary of the answers to each question:

1. Operations Performed by the Functions
film_in_stock: Returns films that are currently available in stock.

film_not_in_stock: Returns films that are not available in stock (either rented or out of inventory).

inventory_in_stock: Returns inventory items that are in stock.

get_customer_balance: Calculates the customer's balance based on rentals, payments, overdue charges, and rewards.

inventory_held_by_customer: Returns films currently rented by a specific customer.

rewards_report: Generates a report of customers' accumulated reward points.

last_day: Returns the date of the last rental or transaction in the system.

5. What are group_concat and _group_concat?
They combine multiple values into one string. Example: If a customer rented 3 films, it can show them like this:
'Film1, Film2, Film3'

Used in reports where we want a list in one row.

6. What does last_updated do?
It returns the last time something was updated (like a film, customer, or rental).

7. What is tmpSQL in rewards_report?
It stores a SQL command as text and runs it later. This is called dynamic SQL.

8. Can we remove EXECUTE and not use dynamic SQL?
Yes, if we don’t need flexibility, we can just write the query directly. It’s simpler and safer without dynamic SQL.
